# Запись на звонок

Сервис, где гость без регистрации бронирует время для звонка с единственным владельцем.

## Роли

**Владелец**:
Единственный хозяин календаря, задан заранее. Заводит типы встреч и смотрит предстоящие брони.
_Avoid_: админ, хост, организатор

**Гость**:
Человек без учётной записи, который записывается на звонок по имени и email.
_Avoid_: клиент, пользователь, посетитель

## Расписание

**Тип встречи**:
Шаблон звонка с названием, описанием и длительностью; гость выбирает его первым.
_Avoid_: услуга, событие, event

**Слот**:
Свободный интервал `[start, end)` длиной в тип встречи, начинающийся на сетке 30 минут в рабочие часы.
_Avoid_: окошко, время, таймслот

**Окно записи**:
14 календарных дней, начиная с сегодняшнего, в которые можно выбрать слот.
_Avoid_: горизонт, период

**Бронь**:
Занятый гостем слот конкретного типа встречи. Брони разных типов не пересекаются.
_Avoid_: запись (как сущность), встреча, appointment

## Страницы

**Главная страница**:
Первая страница: объясняет сервис и ведёт на страницу записи кнопкой «Записаться».
_Avoid_: лендинг, стартовая

**Страница записи**:
Путь гостя: тип встречи → день → слот → имя и email → бронь.
_Avoid_: каталог, форма бронирования

**Страница владельца**:
Создание типов встреч и список предстоящих броней.
_Avoid_: админка, кабинет
