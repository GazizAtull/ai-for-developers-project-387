# Переключение страниц без роутера

Главная страница, страница записи и страница владельца переключаются состоянием в `App`, без React Router и без URL-путей. Страниц три, Spring отдаёт один `index.html`, и роутер добавил бы зависимость и настройку fallback на сервере. Если понадобятся прямые ссылки на страницы, подключаем роутер и fallback в Spring.

## Considered Options

- React Router с путями `/`, `/book`, `/owner`: отклонён до появления прямых ссылок.
