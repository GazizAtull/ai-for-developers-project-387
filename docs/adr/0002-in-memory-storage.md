# Хранение в памяти процесса

Типы встреч и брони хранятся в памяти бэкенда, перезапуск их сбрасывает. Для учебного сервиса это убирает базу данных и миграции; защиту от двойной брони даёт замок в `CalendarService`. Переход на БД потребует перенести эту проверку в транзакцию с ограничением на пересечение.
