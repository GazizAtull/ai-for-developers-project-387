# Один владелец без авторизации

Сервис упрощённый: владелец один и задан заранее, гость записывается по имени и email. Авторизацию, личные кабинеты и внешние календари сознательно не делаем, поэтому страница владельца открыта без входа. Если понадобится несколько владельцев, это будет новое решение с моделью пользователей.
